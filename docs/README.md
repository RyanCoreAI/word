## 一句话

一套代码同时出 **iPhone App 和安卓 App**。App 显示单词并自动朗读，遮住词性和中文。点「认识」丝滑切到下一个词；点「不认识」立刻显示释义，这个词进入下一组，直到再认识 2 次才算掌握。另有「听音辨词」模式：只放发音，不显示拼写。整本 ECDICT 词典（770,611 条）导入服务器数据库，学习时默认只出 11,481 个考试词，过滤掉 a、the、is 这类基础词。进度存在手机上，并同步到 `yanxai.com` 的服务器，换手机也不会丢。

## 已定的关键决定

Codex 不要自行更改下面这些决定；要改，先由你确认，再改文档。

| # | 决定 | 理由 |
|---|---|---|
| D1 | App 用 **React Native + Expo**（TypeScript），一套代码出 iOS 和安卓 | 动画在原生 UI 线程跑，切换更顺；iOS 用 EAS 云端打包，**不需要 Mac**；Codex 最熟悉 TypeScript |
| D2 | **离线优先**：词包和进度都存在手机本地 SQLite，点按不等网络；后台再同步到服务器 | 切换要顺畅，进度不能丢；地铁里没网也能背 |
| D3 | 服务器用 **Node.js 24 LTS + Fastify + PostgreSQL 17**，和 App 共用同一份 TypeScript 规则代码（`packages/core`） | 手机和服务器算出来的结果必须一模一样 |
| D4 | 整本 **ECDICT**（MIT 许可，770,611 条）全部导入 PostgreSQL；App 内置 19,094 词的「词包」（约 1.4 MB） | 满足「整本入库」，App 又小又快 |
| D5 | 默认词库：四级、六级、考研、托福、雅思、GRE，过滤基础词后 **11,481 词** | 详见 `03-dictionary-data.md` 的过滤规则 |
| D6 | 音标：美音取自 CMUdict（BSD 许可），英音由 ECDICT 旧式音标转换成现代 IPA | ECDICT 自带的是旧式音标（如 `i'læbәreit`），直接显示不规范 |
| D7 | 发音：用 **Azure 神经网络语音**一次性生成美音和英音 MP3，放到自己的 CDN（`cdn.yanxai.com`）；手机缓存；没网时用手机系统自带的朗读 | 版权干净、音质统一、速度快；不依赖第三方词典的非公开接口 |
| D8 | 账号：打开即用（**匿名账号**），可选**绑定邮箱**（验证码，不设密码）用于换机恢复 | 不用注册门槛；苹果不要求「通过 Apple 登录」 |
| D9 | 规则：不认识 → 下一组再出现；之后**连续认识 2 次**才算掌握；中途又不认识，认识次数清零重来；第一次见就认识，直接算掌握 | 你的需求 + 原型 1-3 的说明 |
| D10 | 服务器先放**香港**（不用备案）；要上国内应用商店时再迁到大陆并备案 | 先快速上线自用，再决定要不要公开上架。详见 `09-release.md` |
| D11 | 界面 v1 只做**浅色**、只做**手机竖屏**、只有**简体中文** | 原型只验收了这些；深色模式等新界面要先出图验收 |

## 开发顺序概览

见 `10-milestones.md`。共 11 个里程碑（M0–M10），每个里程碑一个 PR，按顺序做：

```
M0 仓库脚手架 → M1 学习规则核心库 → M2 词典数据管线 → M3 服务器 API
→ M4 发音音频 → M5 App 骨架 → M6 学习页（两种模式） → M7 生词本/设置/账号/同步
→ M8 官网 → M9 部署上线 → M10 测试与发布
```

## 还没定、但不影响开工的事

1. **App 名字**：上架前定。代码里统一用 `APP_NAME` 常量，改名只改一处。
2. **要不要上国内应用商店**：决定服务器要不要迁到大陆、要不要做 ICP 备案和 APP 备案（`09-release.md` 第 4 节）。自用和小范围分发（TestFlight + 官网下载 APK）不需要。
3. **发音人**：M4 时听样音选。
