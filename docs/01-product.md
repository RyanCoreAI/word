## 2. 名词

| 名词 | 含义 |
|---|---|
| 词包 | App 内置的 19,094 个可学的词（含音标、释义、标签），见 `03-dictionary-data.md` |
| 词库范围 / scope | 用户选中的考试标签集合，如四级 + 六级；决定新词从哪里出 |
| 组 / group | 一次连续学习的 N 个词（默认 20）。每组有序号（第 13 组），只用一种模式 |
| 新词 | 从没出现过的词 |
| 复习词 | 状态是「学习中」的词，会在后面的组里再出现 |
| 学习中 | 点过不认识、还没再连续认识够次数的词 |
| 已掌握 | 第一次见就认识，或者不认识后连续认识够了次数 |
| 生词本 | 所有点过「不认识」（不认识次数 > 0）的词 |

## 4. 页面规格

下文「（图 x-y）」指 `design/mockups/` 第 x 张图里的第 y 个手机。

### P0 隐私同意（图 4-1）

- **何时出现**：第一次打开；或隐私政策版本号（`PRIVACY_VERSION` 常量）大于已同意的版本时。
- **同意之前**：不发任何网络请求，不生成设备 ID，不初始化任何统计或崩溃上报 SDK。这是国内应用商店检测的硬性要求。
- 背景是欢迎画面（App 图标、名字、一句标语），上面盖一张底部卡片：标题「欢迎使用」，3 条要点，两个协议链接，「同意并继续」主按钮，「不同意」文字按钮。
- 点「同意并继续」：记录 `consent_version` 和时间 → 生成设备 ID → 后台注册匿名账号（失败也不影响使用，下次联网再试）→ 进入 P1（第一次）或 P2。
- 点「不同意」：卡片内容换成第二屏：「不同意的话无法使用学习功能，因为进度需要保存在你的手机上」，按钮「再看看」/「退出」。安卓点「退出」关闭 App；iOS 不允许程序自己退出，只回到第一屏。
- 点协议链接：用应用内浏览器打开 `https://yanxai.com/terms` 或 `/privacy`。

### P1 选词库（图 4-2）

- 只在第一次出现；以后在 P8 设置里改。
- 8 个可多选的卡片：高考、四级、六级、考研、托福、雅思、GRE、高频补充。每张卡片显示**按当前「过滤基础词」开关计算的**词数（开：1,567 / 2,469 / 4,176 / 3,472 / 5,928 / 3,542 / 7,042 / 5,242）。
- 默认选中：四级、六级、考研、托福、雅思、GRE。
- 「过滤基础词」开关，默认开。说明文字：「跳过 a、the、is 这类最常见的词」。
- 底部「去重后共 11,481 词」，随勾选和开关实时变化（本地 SQL 计数，< 50 ms）。
- 一个都没选时，「开始学习」按钮置灰，总数行显示「至少选一个词库」。
- 「开始学习」→ 保存设置 → 进入 P2（不会自动开始学习）。

### P2 首页（图 3-1）

从上到下：

1. 日期（`10月21日 · 周三`，本机时区）和标题（`APP_NAME`）；右侧「连续 N 天」小标签（N = 0 时不显示）。
2. **进度卡**：圆环 + 数字。
   - 圆环：绿色段 = 已掌握比例，黄色段（紧跟其后）= 学习中比例。
   - 中间：已掌握百分比，保留 1 位小数。
   - 右侧大字：`已掌握数 / 当前词库总数 词`；下方 `学习中 X · 未学 Y`；再下方 `今天 a 组 · 认识 b · 不认识 c`（今天没学时这一行改为「今天还没开始」）。
   - 口径见 `02-learning-rules.md` 第 7 节。
3. **继续卡**（深色）：只在有未完成的组时显示。`继续上次进度`，`第 13 组 · 看词记忆 8 / 20`，点整张卡继续。
4. **两个模式卡**：看词记忆、听音辨词。点了以后：
   - 没有未完成的组 → 新建一组，进入学习页。
   - 有未完成的组，且模式相同 → 直接继续这一组。
   - 有未完成的组，且模式不同 → 弹出 P11。
5. **不认识最多**：生词本前 2 名（单词 + 简短中文 + ×次数），右上「生词本 ›」跳到 P6。生词本为空时整块不显示。
6. 底部标签栏。

**词库全部学完**（没有新词，也没有复习词）：模式卡区域换成一张卡片「当前词库已全部学完 🎉」，两个按钮「刷生词本」「去设置添加词库」。

### P3 学习页 · 看词记忆（图 1）

**顶部**
- 左：返回（回到 P2，进度已自动保存，不弹确认）。
- 中：`看词记忆`；副标题 `第 {seq} 组 · 新词 {n} · 复习 {r}`；生词本组显示 `生词本 · {n} 词`。
- 右：齿轮 → 以模态方式打开 P8。口音、自动朗读、朗读遍数、慢速、振动**立即生效**；词库、每组词数、掌握标准、顺序**从下一组生效**。
- 进度行：`{当前序号} / {组大小}`；右侧 `认识 a`（绿）`不认识 b`（红），统计本组已答（不含已撤销）。
- 分段进度条：每个词一格；绿 = 认识，红 = 不认识，黑 = 当前，灰 = 未到。组大小 > 30 时格子间距从 3 改为 2。

**卡片 · 状态 A（未作答，图 1-1、1-3）**
- 标签行（最多一行，放不下就截断）。顺序：
  1. `复习`（黄，带循环图标）：这个词出组时是「学习中」。
  2. `不认识 ×N`（红）：累计不认识次数 > 0。
  3. `●○ 已认识 k/M`（绿）：学习中，且已连续认识 k 次（k ≥ 1），M = 掌握标准。
  4. 考试标签（灰）：按 四级 六级 考研 托福 雅思 GRE 高考 的顺序，最多 4 个。
- 单词：衬线字体，居中；默认 50 pt；单词超过 11 个字母时按宽度自动缩小，最小 32 pt；含连字符的长词可以在连字符处换行。
- 音标行：口音小标签（`美`/`英`）+ `/音标/` + 喇叭按钮。显示规则见 `03-dictionary-data.md` 第 5.3 节。没有任何音标时只显示喇叭按钮。
- 朗读中：喇叭按钮变成蓝色实心并带光晕，下方显示声波动画 + `自动朗读中`；播完恢复。
- 遮罩：固定高度 182 pt，斜纹背景、虚线边框，文字「词性和中文已遮住」「点「不认识」立即显示」。
- 底部按钮：左「✕ 不认识」（浅红底红字），右「✓ 认识」（绿底白字），等宽，高 62 pt。
- 按钮下方提示行：手机上显示「点喇叭可以重听」（原型里的键盘提示 v1 不做）。

**点「认识」**
1. 立即触发轻振动（设置里开了的话）。
2. 当前卡片向左滑出，同时下一张卡片进场（参数见 `07-mobile-app.md` 第 4 节），顶部出现绿色小条「✓ 认识 · 撤销」，1.2 秒后自动消失，点「撤销」可撤回（见下）。
3. 下一个词进场即开始朗读。
4. 这是本组最后一个词时：滑出后直接进入 P5 小结。

**点「不认识」→ 状态 B（图 1-2）**
- 不换卡片，原位变化（150 ms）：
  - 遮罩淡出、释义淡入，区域高度不变（最小 182 pt；释义超过 4 行时只显示前 4 行，详情里看全部）。
  - 标签行出现或更新 `不认识 ×N`（带一次轻微放大回弹）。
  - 释义框下方一行：左 `已加入第 {seq+1} 组`，右 `再认识 ○○ 次才算掌握`（M 个空心圆）。
  - 按钮换成「↺ 撤销」（浅灰，窄）和「下一个 →」（深色，宽）。最后一个词时「下一个」改为「查看小结」。
  - 提示行：`点卡片任意处也能继续`。
- 「不认识」在点按的这一刻就写入数据库，不等点「下一个」。
- 状态 B 下点卡片空白处，效果等于点「下一个」。

**释义显示规则**
- 每行一个词性：左边词性小标签（蓝底斜体，如 `adj.`），右边中文义项用「；」连接。
- 只显示常规词性行；医、法、经、计等专业释义和网络释义只在 P7 详情里显示。
- 没有任何常规释义行的词（默认词库里 47 个）：显示专业释义行，词性小标签换成灰底的领域名（如 `计`）；连专业释义也没有时，显示网络释义。
- 无词性的普通行：不显示词性小标签。

**撤销**
- 可以连续撤销，一直退回到本组第一个词；不能撤销到上一组。
- 撤销「不认识」（状态 B 的撤销按钮）：这个词的数据恢复到点按之前，卡片回到状态 A（遮罩重新盖上）。
- 撤销「认识」（点顶部小条）：上一张卡片从左侧滑回，处于状态 A，数据恢复。
- 已撤销的作答不计入任何统计和次数。

### P4 学习页 · 听音辨词（图 2）

和 P3 的区别：

- 标题 `听音辨词`。标签行只有一个 `听音`（蓝）。复习、次数这些标签在状态 A 不显示，避免提示。
- 卡片中间是大播放按钮（140 pt 圆形），下方声波 + `正在朗读 · 第 1 遍`（读第 2 遍时显示第 2 遍），再下方 `拼写和释义已隐藏`。播完后文字变成 `点按钮再听一遍`。
- 卡片底部 3 个按钮：
  - `再听一遍`：从头播放 1 遍。
  - `慢速`：开关，打开后以 0.7 倍速播放，并立即重播一遍；状态保存到设置（`slow`）。
  - `美音`/`英音`：点击切换口音，立即重播；保存到设置（`accent`）。
- **状态 B**（点不认识，图 2-2）：播放区淡出；显示 P3 状态 B 的全部内容（标签行、单词、音标、释义、下一组提示），并**自动用当前口音再读一遍**，提示文字是 `对照拼写再读一遍`。
- 「认识」的切换效果、撤销规则、最后一个词进入小结，都和 P3 相同。
- 点大播放按钮 = 再听一遍。

### P5 一组小结（图 3-2）

- 顶部：左上 ✕（回首页），标题为本组模式名。
- 对勾图标、`第 {seq} 组完成`、`{n} 个词 · 用时 {m} 分 {s} 秒`（从开始到最后一次作答，不含退出 App 的时间，见 `02` 第 7 节）。
- 3 个数字块：认识（绿）、不认识（红）、新掌握（蓝，`+k`）。
- 列表标题：`这 {k} 个词会在第 {seq+1} 组再出现`。列表内容 = 本组结束后状态为「学习中」的词：
  - 本组不认识的词在前（按累计不认识次数从高到低），右侧红/黄 `×N`（N ≥ 3 红，否则黄）；
  - 本组认识了、但还没掌握的复习词在后，右侧显示 `●○`。
  - 单行：单词 + 简短中文（第一个词性行的前 2 个义项）+ 次数。超过 6 个词时列表可以滚动。
  - k = 0 时整块换成「这组全部掌握了 👏」。
- 主按钮 `开始第 {seq+1} 组 →`（沿用本组模式）；下方小字 `第 {seq+1} 组 = {复习数} 个复习词 + {新词数} 个新词`（按当前设置预估）。
- 生词本组的小结：主按钮改为 `再刷一组生词` 或 `回首页`（没有可刷的词时）。

### P6 生词本（图 3-3）

- 标题「生词本」，上方小字「所有点过「不认识」的词」。
- 搜索框：同时匹配英文前缀和中文包含，输入后 150 ms 去抖，本地查询。
- 分段：`学习中 {n}` / `已掌握 {n}` / `全部 {n}`。
- 排序行：左 `按不认识次数 ↓`，点击在「按不认识次数」和「最近不认识」之间切换；右侧按钮 `▶ 刷这 {n} 个词`，n = 当前分段里的词数，上限显示为每组词数（例如分段有 214 个、每组 20 个时，显示「刷这 214 个词」，实际出前 20 个）。
- 每行：单词（衬线）+ 音标（小灰字）；下一行简短中文；右侧 `×N` 和掌握进度圆点（已掌握显示实心 ✓）。
- 点某行 → P7。
- 空状态：「还没有不认识的词。背单词时点「不认识」的词会出现在这里。」
- 列表用虚拟列表，几千行也流畅。

### P7 单词详情（图 5-1）

- 底部弹层，占屏幕约 85% 高，可下拉关闭，点遮罩关闭。
- 考试标签、单词（40 pt 衬线）。
- 两行音标：`美 /…/ 🔊`、`英 /…/ 🔊`，各自播放对应口音；没有的那行不显示。
- 释义框：全部常规词性行；如有专业释义，加小标题「专业释义」，每行左边是灰底领域标签；如有网络释义，加小标题「网络释义」。
- 3 个数字块：不认识 N 次（红）、认识 M 次（绿）、状态（学习中 + 圆点 / 已掌握 / 未学）。
- 时间线：`首次学习 10月3日（第 2 组）`、`最近一次不认识 10月20日（第 12 组）`、`下一次出现：第 {当前最大组号+1} 组`（只对学习中的词显示）。

### P9 账号与数据（图 5-2）

- 账号卡片：
  - 未绑定：头像占位 + `未绑定邮箱` + `绑定后换手机也不丢进度` + 「绑定」按钮 → P10。
  - 已绑定：显示邮箱（中间打码，如 `ya***@gmail.com`）+ `已绑定`。
- 同步状态：`已同步 · 刚刚` / `已同步 · 5 分钟前` / `有 12 条记录未同步 · 离线`（橙色）/ `同步失败，点此重试`（红色）。点击立即同步。
- 数据：
  - 导出学习记录 → 生成 CSV，调起系统分享面板。列：`word,chinese,status,wrong_count,right_count,first_seen,last_seen,last_wrong`。UTF-8 带 BOM（Excel 打开中文不乱码）。
  - 重置学习进度 → 二次确认弹窗（输入「重置」两个字才能确认）→ 本地和服务器都清空答题记录、单词状态和组记录；设置保留。
- 关于：隐私政策、用户协议（应用内浏览器打开官网页面）、词典与开源许可（App 内页面，列出 ECDICT MIT、CMUdict BSD、字体 OFL 许可全文）、版本号 `1.0.0 (build)`。
- 注销账号（红字）→ 确认页：说明会删除什么 → 二次确认（输入「注销」）→ 调用接口 → 清空本地数据 → 回到 P0。离线时提示「需要联网才能注销」。

### P10 绑定邮箱（图 5-3）

1. 输入邮箱 → 「发送验证码」。校验格式；60 秒倒计时后才能重发。
2. 6 个验证码格子，输满 6 位自动提交，也可以点「绑定」。
3. 结果：
   - 邮箱没被用过 → 绑定到当前账号，提示「绑定成功」，返回 P9。
   - 邮箱已有账号（比如旧手机）→ 两边答题记录合并到邮箱账号（规则见 `06-api-sync.md` 第 5 节），提示「已找回 {n} 个词的学习进度」，App 做一次完整同步。
   - 验证码错误：格子抖动一下，提示「验证码不对，还可以试 {k} 次」；5 次错误后作废，需要重新发送。
   - 过期：提示「验证码已过期，请重新发送」。

### P11 未完成的组（图 4-3）

- 底部弹层，沙漏图标，`第 {seq} 组还没学完`，`{模式} · 已完成 {cursor} / {size}`，分段进度条。

- 小字 `已经答过的 {cursor} 个词，记录都会保留`。
