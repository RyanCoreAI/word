# 当前网页需求与验收

本轮按用户批准的复述原型继续实现，范围仅 `RyanCoreAI/word` 和 `word.yanxai.com`。旧原生 App/付费服务器方案继续作为历史资料，不新增账号、收费 API、D1 或 R2。

## 数据覆盖的实质限制

当前词汇补充版本 `lexical-zh-690ef2bf155346881a4b`：8,834 个不同短语，3,913 / 19,106 个学习词有内容，3,875 个有短语。1,325 个学习词有短语近义，47 个有小规模编辑的精确单词近义，两词重合，并集 1,370。原 2,291 条合格近义关系逐条保留。

这不是全词覆盖、官方雅思替换全集或可靠词频排名。没有来源的词明确留空，不能为满足数量而生成看似准确的中文或万能替换。ECDICT、维基词典和 WordNet 使用各自许可；完整归档可校验、可重建。`tools/phrases/README.md` 记录筛选、抽样与局限。

复述参考答案用于自查，不自动判定自由复述的语义、语法、发音正确程度，不产生雅思分数。ASR 会误识，须结合原音与参考核对。四篇是项目编辑材料，没有官方难度认证。

## 检查与证据

本轮本地检查：`npm run lint`、`npm run typecheck`、`npm test`（151 项）、三条 Python unittest discover（词典9、短语33、ASR7）、完整 build。额外真实 Chrome 检查：

- `tools/browser-smoke.mjs`：17 项原学习/撤销/设置/备份/响应布局回归。
- `tools/experience-smoke.mjs`：10 项圆环/日历/首次认识/触感/斩/离线进度。
- `tools/new-learning-smoke.mjs`：11 项原生触摸回看、纵向阅读、短语、昨日复习与安装布局；状态 fixture 明确标为测试数据。
- `tools/phrases/browser-smoke.mjs`：7 项真实来源、空状态、损坏重试及离线读取。
- `tools/asr/browser-smoke.mjs`：5 项真实模型和 MediaRecorder/离线 Worker，公开 JFK 文件输入，无假转写。
- `tools/retell-smoke.mjs`：完整四阶段页面、真实录音与保存、离线再识别、跨文章隔离、取消、缓存损坏修复和权限拒绝。
- `tools/visual-reference.mjs` 及 `design-qa.md`：原始 Claude 页面与实际页面的相同视口并排检查，新复述参照已批准图板。

发布后执行 `tools/verify-release.mjs` 校验线上 HTML、应用/复述脚本和样式、词库样本、全部新短语分片/来源/许可、全部 ASR 分片，与本地构建逐字节比较；再对公开 URL 运行浏览器流程。结果保存在当前交付工作区 `outputs/word-retell`，不将用户数据或大体积生成物提交。

## 本机数据与真机边界

单词完整备份包含进度、每日记录、每日复习和回看轨迹。复述另存每篇最近一次完成的文字/录音，页面可复制导出文字、单独下载录音；当前不包含在单词备份中，也没有语音记录跨设备恢复/合并。

Chrome 的安卓尺寸与触摸仿真、文件麦克风和自动化音频事件都不是实际安卓手机验收。安装到系统桌面、Samantha 是否可用、真实发音听感、硬件震动、低端机速度与麦克风效果仍由实际设备决定，不把这些未测项写成已通过。
