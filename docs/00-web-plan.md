# Word 免费网页实施方案

2026-10-21：用户在六张原型及原技术方案审查后授权开始实现。本文覆盖历史原生/付费服务方案；原 `01`–`10` 文档保留为讨论历史，不代表已实现或已测试。

## 目标与范围

在 `word.yanxai.com` 使用的手机/桌面网页，支持添加主屏幕。无需购买开发者账号、云服务器或语音服务。用户随后明确要求一直推进到上线、不再询问，且只操作本项目；本次范围包括本项目必要的提交、发布和子域接入。

## 验收标准

- 看词隐藏中文与词性；听音隐藏拼写、中文和词性，声音实际开始后才允许作答。声音失败可以重试或跳过，跳过不算不认识。
- 首次出现的词点认识后，先保存答案并短暂显示词义，再自动下一词；已作答过的词认识时立即继续。不认识只计一次并原位揭晓，主动继续。未掌握词下一组优先且不因组大小缩小遗漏；连续两次认识完成本轮，遇不认识清零。
- 看词/听音分别保存进度。每次操作写入本地数据库后确认；存储失败阻止静默推进。撤销恢复计数与位置；重复点击和多标签页不能覆盖新进度。
- 刷新、关闭页面、模式切换恢复学习；完整备份包含进度/队列/设置/词库版本，导入严格验证并原子替换。
- 全量固定版本词典导入 SQLite 并导出静态分片；学习包独立。极基础词按明确短名单过滤，用户可永久跳过/恢复。数据和统计真实可重建。
- 全量词典在浏览器分片导入，支持暂停/重试；空间不足保留有效状态。字典版本变化不能静默重置进度。
- 真实浏览器检查桌面和手机尺寸、主要流程、错误状态与离线恢复。设备实际声音质量仍须用户手机试听。
- 首页蓝色圆环可切换看词/听音进度，打开应用旋转一次；搜索移到首页，覆盖学习包与已下载完整词典。
- 已批准的新版首页顺序为圆环卡在上、本书今日计划卡在下。计划按词书和看词/听音分别保存；显示真实待学新词、昨日错词复习、剩余/总天数，达标不限制继续学习。
- 计划的开始日、截止日按本地日历计算，包含今天。每天首次建立目标时按剩余未接触词数除以剩余天数向上取整，当天固定；修改截止日可明确重算当天目标，保留真实已学计数与历史。已有进度只扣除未学余额，不补造首次学习日期或旧打卡。
- 首次真实作答才计本模式的一个新词，不认识也算接触，重复作答不重复抵扣新词；本书昨日错词另计去重的一轮复习。两项达到目标才可打卡，答错仍继续原有巩固规则；撤销同时回退今日计数与打卡状态。
- 达标礼炮先保存每日一次凭据，再播放；刷新、恢复备份或撤销后再达标不重复领取。尊重减少动画和后台状态，零任务日可打卡但不虚构学习成就或播放礼炮。
- 打卡图采用真实已保存的本书/模式当日新学与复习数量，提供 20 张同源风景切换、PNG 保存与系统分享。二维码固定指向 `https://word.yanxai.com/`，不编码个人进度、备份或设备标识，不接远程二维码服务。
- 日历按设备本地日期记录每日去重词数及每词两模式的认识/不认识次数，支持撤销及备份恢复。旧数据不补造未知日期。
- 安卓 PWA 安装入口、独立窗口、安全区与键盘缩放；禁用双击放大，保留双指缩放及系统减少动画偏好。
- 开始学习轻震与斩词刀切音效可分别关闭；音效只在用户点击并成功保存斩词后播放。触感/音频不可用不得阻塞学习，不把浏览器接受震动请求称为真实硬件验收。
- 用户否决旧自动关联短语后，改为按词条精确编辑的常用搭配，含中文与必要语法限制、权威词典用法链接。揭晓和回看直接显示，详情可展开；未核对词不显示补充区域。旧词组和 WordNet 近义块全部撤下，不按数量填充，不宣称全词覆盖。
- 右滑回看、左滑返回至当前待学词；最近 1,000 次轨迹与进度分别保存，回看不等于撤销，不产生答案或计数。新旧备份校验兼容。
- 昨日各模式真实不认识记录在今日下一新组优先检验，含后来掌握的词；不打断当前组，斩过的词除外，检验和撤销标记持久保存。
- 新增「复述」导航，按已认可第三张原型的选文/阅读/录音/参考对照布局实现。首批四篇附研究和官方事实来源，提供两份参考、中文要点和易错提示。只接麦克风，不做输入听写、不伪造语义评分。
- 免费本机 Whisper tiny.en q8 WASM 识别：明确点击后下载约 73 MB，同源校验并缓存（约 146 MB），录音不上传；取消、暂停、回听、失败重试和离线再用。每篇最近一次完成记录独立保存，文字与录音分别导出，原单词备份范围明确。

## 实现

2026-10-23 用户随后明确要求直接安卓安装包，增加最小 Trusted Web Activity 工程，固定 Chrome 稳定版和 Word 独立签名，官网提供 APK 与数字资产关联。继续复用现有网页，不引入 WebView 桥或第二套学习数据库，不购买商店账号；这覆盖此前只交付 PWA 的选择，但不恢复历史 React Native/服务端方案。APK、元数据和关联文件按实际签名/哈希验证，下载与域名验证路由直接走静态网络，不缓存为应用外壳。Android 7.0+，具体设备和 Chrome 的语音/权限仍需实际验收。

React + TypeScript + Vite；纯函数规则 `packages/core`；Zod 校验外部输入；IndexedDB 保存词典和学习快照，revision 比较避免旧标签页覆盖。PWA 缓存应用外壳和已加载学习包；词典在首次同意下载后访问同源静态数据，不收集身份、无跟踪、无外部分析脚本。

学习计划保存时确定词书与基础词过滤范围，排除已斩词；此后斩词动态排除，避免留下不能完成的日目标。修改全局过滤不会暗改已保存计划，界面提示后由用户保存计划更新范围。切换词书或模式不会清除其它计划；共享词条可沿用真实学习记录，不把不同词书或模式的数量相加当作独立单词总量。旧队列仍可保留其它词书生词，但它们不能污染本书计划计数。

完整单词备份包含计划范围、日期、每日去重记录、打卡和礼炮凭据。新日目标保存、作答、领取礼炮与打卡分别是 revision 加一的原子操作；无变化不写入。午夜不清进度、不打断当前组，截止日过后仍可学习；期限和计划记录有上界，错误须提示，不能静默重置。编辑器“重置”只调整待保存的截止日期，不清学习记录。

20 张风景位于 `apps/web/public/images/check-in/01.png` 至 `20.png`，随静态站点发布，但不进入 Service Worker 安装预缓存。实际选中的图片才请求并缓存；已缓存图片可离线再用，未访问过的风景需要联网，失败保留已有图或显示可重试状态。礼炮与分享生成代码按需加载，使用固定版本 canvas-confetti、qrcode 及对应许可；二维码、字体和背景均在本机/同源处理，不上传学习数据。

按最新用户要求，发音严格使用本机英文声音：优先本地 Samantha，其次同口音本地声音；显式选择的声音缺失时明确提示，不自动切换到远程服务或本站 Piper。只有真实 onstart 才允许听音作答。安卓声音取决于系统语音数据及浏览器暴露能力，不能把 Windows 上的模拟测试称为安卓或 Samantha 真机试听。检查错误/超时、切词取消与后台停止；音标保留词典来源，不混造英美差异。旧朗读音频管线保留历史资料，当前朗读不生成音频分包；复述识别使用单独的 WASM 模型管线，不将识别模型混称为发音服务。

代码保存在现有 GitHub 仓库。实施中确认本机已有有效 Cloudflare Workers OAuth 授权，可在免费静态资源托管上直接绑定 `word.yanxai.com` 并自动生成 DNS/证书，因此最终发布采用独立的 `yanxai-word` 静态资源项目，不需要新增账号或手动配置 DNS。没有 Worker 业务函数、付费套餐、D1、R2 或新密钥。全量生成物不提交，构建前运行固定词库管线，最终 `dist` 可部署。用户进度和备份绝不上传公开仓库。

## 风险与非目标

常用搭配由 `apps/web/src/data/collocations.ts` 明确关联到词条，当前为 33 个词条、39 条搭配，全部命中真实学习词库；中文为编辑释义，来源只作核对用法而非复制整段释义或例句；随应用外壳离线缓存。旧通用词典短语管线保留历史但不再生成或发布，不清除用户任何历史进度。没有资料的词留空，不自动编造短语或同义关系。

按用户“声音达不到要求就取消”的指示，文章合成朗读入口已撤下，保留阅读 → 脱稿麦克风复述 → 参考对照与录音回听。Web Speech 的本地声音由设备提供，语速、音高与固定停顿不能保证篇章重音/自然度，不以事件测试代替听感验收。单词本机声音保持原规则。能力边界依据 [Web Speech 官方规范](https://webaudio.github.io/web-speech-api/#utterance-attributes)。

ASR 仍是本机机器学习识别，避免的是付费/外部 API，并非宣称没有使用模型。转写不等于判断复述正确或发音标准，采用编辑参考与中文要点自查。模型和浏览器内存消耗对低端安卓有影响，需真机接受；Chrome 文件麦克风、浏览器仿真和离线测试不能代替硬件体验。

浏览器清理数据或设备丢失会丢本地记录，需要主动导出备份。免费版无账号和云同步；无商店发布；无付费音频；无长期记忆算法承诺。多设备通过备份迁移，不合并两套并发记录。不能穷尽所有设备的浏览器行为，需记录已验证范围。

系统图片分享取决于 HTTPS、用户点击、浏览器和手机已安装应用。只有 `navigator.canShare({ files })` 支持时调用系统分享；不能承诺浏览器直接调起指定微信/QQ会话，也不能把“已交给系统”说成“对方已收到”。不支持或失败时提供保存 PNG、复制官网链接后手动发送。依据 [Web Share API 的可分享数据检测](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/canShare) 和 [原生分享限制](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)。安卓通过 Chrome 安装 PWA，无需开发者账号；真实手机安装、分享目标、相册下载及动画性能仍须与桌面/移动仿真证据分开说明。

## 验证与交付

测试纯规则、状态校验、真实 IndexedDB 语义模拟、分片断点与校验、音频生命周期；运行 lint/typecheck/test/build。网页真机前的本地浏览器检查结果单独记录，不把合成测试视为真实手机音频验收。

构建额外断言恰好 20 张编号风景图：校验 PNG 签名、块 CRC、像素解压/扫描行、尺寸至少 1080×800，SHA-256 不重复；不把文件哈希不同当作人工视觉验收。`node tools/build-offline.mjs --check-scenes-only` 只读验证源图，不改 `dist`。发布后的 `tools/verify-release.mjs` 对全部本地 JS/MJS/CSS 分块、20 张风景、许可与原有词库/ASR抽样和模型分片逐文件比较公开字节；不能用构建成功代替线上检查。
