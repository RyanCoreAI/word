# Word 免费网页实施方案

2026-10-21：用户在六张原型及原技术方案审查后授权开始实现。本文覆盖历史原生/付费服务方案；原 `01`–`10` 文档保留为讨论历史，不代表已实现或已测试。

## 目标与范围

在 `word.yanxai.com` 使用的手机/桌面网页，支持添加主屏幕。无需购买开发者账号、云服务器或语音服务。用户随后明确要求一直推进到上线、不再询问，且只操作本项目；本次范围包括本项目必要的提交、发布和子域接入。

## 验收标准

- 看词隐藏中文与词性；听音隐藏拼写、中文和词性，声音实际开始后才允许作答。声音失败可以重试或跳过，跳过不算不认识。
- 首次出现的词点认识后，先保存答案并短暂显示词义，再自动下一词；已作答过的词认识时立即继续。不认识只计一次并原位揭晓，主动继续。未掌握词下一组优先且不因组大小缩小遗漏；连续两次认识完成本轮，遇不认识清零。
- 看词/听音分别保存进度。每次操作写入本地数据库后确认；存储失败阻止静默推进。撤销恢复计数与位置；重复点击和多标签页不能覆盖新进度。
- 刷新、关闭页面、模式切换恢复学习；完整备份包含进度/队列/设置/词库版本，导入严格验证并原子替换。
- 全量固定版本词典导入 SQLite 并导出静态分片；学习包独立。极基础词按明确短名单过滤，用户可永久跳过/恢复。数据和统计真实可重建。
- 全量词典在浏览器分片导入，支持暂停/重试；空间不足保留有效状态。字典版本变化不能静默重置进度。
- 真实浏览器检查桌面和手机尺寸、主要流程、错误状态与离线恢复。设备实际声音质量仍须用户手机试听。
- 首页蓝色圆环可切换看词/听音进度，打开应用旋转一次；搜索移到首页，覆盖学习包与已下载完整词典。
- 日历按设备本地日期记录每日去重词数及每词两模式的认识/不认识次数，支持撤销及备份恢复。旧数据不补造未知日期。
- 安卓 PWA 安装入口、独立窗口、安全区与键盘缩放；禁用双击放大，保留双指缩放及系统减少动画偏好。
- 开始学习轻震与斩词刀切音效可分别关闭；音效只在用户点击并成功保存斩词后播放。触感/音频不可用不得阻塞学习，不把浏览器接受震动请求称为真实硬件验收。
- 看词/听音揭晓和回看直接显示短语、中文及逐义近义表达，详情显示完整资料。使用中文维基词典、ECDICT 原词组和小规模人工核验 WordNet 义项；保留标签/来源/替换限制，不按相似中文猜测关系，不伪称全覆盖或官方雅思词频。
- 右滑回看、左滑返回至当前待学词；最近 1,000 次轨迹与进度分别保存，回看不等于撤销，不产生答案或计数。新旧备份校验兼容。
- 昨日各模式真实不认识记录在今日下一新组优先检验，含后来掌握的词；不打断当前组，斩过的词除外，检验和撤销标记持久保存。
- 新增「复述」导航，按已认可第三张原型的选文/阅读/录音/参考对照布局实现。首批四篇附研究和官方事实来源，提供两份参考、中文要点和易错提示。只接麦克风，不做输入听写、不伪造语义评分。
- 免费本机 Whisper tiny.en q8 WASM 识别：明确点击后下载约 73 MB，同源校验并缓存（约 146 MB），录音不上传；取消、暂停、回听、失败重试和离线再用。每篇最近一次完成记录独立保存，文字与录音分别导出，原单词备份范围明确。

## 实现

React + TypeScript + Vite；纯函数规则 `packages/core`；Zod 校验外部输入；IndexedDB 保存词典和学习快照，revision 比较避免旧标签页覆盖。PWA 缓存应用外壳和已加载学习包；词典在首次同意下载后访问同源静态数据，不收集身份、无跟踪、无外部分析脚本。

按最新用户要求，发音严格使用本机英文声音：优先本地 Samantha，其次同口音本地声音；显式选择的声音缺失时明确提示，不自动切换到远程服务或本站 Piper。只有真实 onstart 才允许听音作答。安卓声音取决于系统语音数据及浏览器暴露能力，不能把 Windows 上的模拟测试称为安卓或 Samantha 真机试听。检查错误/超时、切词取消与后台停止；音标保留词典来源，不混造英美差异。旧朗读音频管线保留历史资料，当前朗读不生成音频分包；复述识别使用单独的 WASM 模型管线，不将识别模型混称为发音服务。

代码保存在现有 GitHub 仓库。实施中确认本机已有有效 Cloudflare Workers OAuth 授权，可在免费静态资源托管上直接绑定 `word.yanxai.com` 并自动生成 DNS/证书，因此最终发布采用独立的 `yanxai-word` 静态资源项目，不需要新增账号或手动配置 DNS。没有 Worker 业务函数、付费套餐、D1、R2 或新密钥。全量生成物不提交，构建前运行固定词库管线，最终 `dist` 可部署。用户进度和备份绝不上传公开仓库。

## 风险与非目标

短语资料采用固定来源快照及各自 CC BY-SA、MIT、WordNet 许可；原始中文和小规模编辑中文义项均可追溯。离线仅限已读取内容。免费公开资料不能保证每个词都有适用搭配，也不提供可靠常用度排序；当前学习词资料覆盖 3,913 / 19,106，不能写成已补全。来源筛选、校验及许可见 `tools/phrases/README.md`。短语故障不影响原有学习队列和本机进度。

ASR 仍是本机机器学习识别，避免的是付费/外部 API，并非宣称没有使用模型。转写不等于判断复述正确或发音标准，采用编辑参考与中文要点自查。模型和浏览器内存消耗对低端安卓有影响，需真机接受；Chrome 文件麦克风、浏览器仿真和离线测试不能代替硬件体验。

浏览器清理数据或设备丢失会丢本地记录，需要主动导出备份。免费版无账号和云同步；无商店发布；无付费音频；无长期记忆算法承诺。多设备通过备份迁移，不合并两套并发记录。不能穷尽所有设备的浏览器行为，需记录已验证范围。

## 验证与交付

测试纯规则、状态校验、真实 IndexedDB 语义模拟、分片断点与校验、音频生命周期；运行 lint/typecheck/test/build。网页真机前的本地浏览器检查结果单独记录，不把合成测试视为真实手机音频验收。
