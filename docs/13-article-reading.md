## 入口与使用流程

底部主导航为「学习、阅读、复述、生词本、设置」五项。新增「阅读」包含材料库与文章生词本两个页签；原主导航的「生词本」继续对应原词书错词，不与文章生词混用。

1. 在「阅读」粘贴正文，或选择 UTF-8 `.txt` 文件，检查标题、正文和可选来源链接。
2. 点击「导入并分析」。先保存正文，再加载经校验的阅读资料，在本机 Web Worker 中分析。
3. 报告显示词汇记录分布、优先确认词和困难段落提示。可先确认一批词，再进入原文。
4. 按段阅读，点击词查看词典义项、候选词条及原文；可标记「认识」「此处不懂」「专名 / 忽略」或撤销本篇标记。
5. 选定可靠词条后加入文章生词本，独立复习，再回原文阅读。

文件选择是本机读取，不是上传。TXT 解码使用严格 UTF-8，支持 BOM，统一 CRLF/CR 为 LF，保留段落与段内文本；乱码、空文件和超限文件明确拒绝，不清空已有文章。相同规范化正文通过 SHA-256 去重，重复导入打开原记录。

本版没有 DOCX、PDF、扫描件 OCR、网页抓取、AI 简化改写、自动语境翻译或整篇合成朗读。来源链接只保存并提供用户主动打开的入口，不自动获取网页内容。单词发音继续使用现有本机语音能力；不恢复用户否决的机械文章朗读。

## 状态、词形与统计口径

阅读主要参考「看词记忆」记录，不用听音进度代替；本篇人工确认优先于旧记录。

| 状态 | 实际含义 |
| --- | --- |
| 有认识记录 | 有可适用的看词完成记录，或在本篇明确确认认识 |
| 需复习 | 对应看词记录仍在学习中；已有历史错误但现已完成的词不会仅因旧错词次数永远归入此类 |
| 明确生词 | 本篇明确选择不懂，或文章复习答错后回流的标记 |
| 待确认 | 词条存在但记录不足、已斩，或词形/大小写存在歧义 |
| 词典未匹配 | 当前已加载词条无法提供可靠匹配，不伪造释义，也不直接当成明确生词 |
| 已忽略 | 用户对本篇主动忽略的专名等词 |

未学过、被基础过滤排除、已斩，都不自动视为认识。点击释义不算答错，阅读次数不算学习完成量。每次分布按实际出现次数统计，另列归并后的不同词形/原形数，避免把「不同生词数 ÷ 总出现次数」当成生词比例。

`familiarCoverage` 为有认识记录的出现次数除以全部非忽略出现次数；它是记录覆盖情况，**不是阅读理解率、语言等级或考试分数**。有依据的分类不足非忽略词数一半时，先提示确认词汇；资料充分后，98% / 90% 的界面分档仅用于粗略选择阅读方式，不保证读懂。

词形归并只使用 ECDICT `exchange` 中实际存在的关系：显式 `0` 原形，以及 `p/d/i/3/r/t/s` 关系的反向索引。两侧拼写必须真实存在，原形必须在阅读资料中；不使用猜测式 stemmer，也不把派生词族整体算作掌握。`studies` 可关联 `study`，但 `saw` / `see`、`left`、`better` 等歧义不能仅凭原形认识就判定熟悉；`US` / `us`、`May` 等保留大小写风险。弹层优先显示精确词条，歧义时要求结合原句选择候选，不自动承诺语境义项正确。

困难段落按需确认出现次数排序；长句提示只依据超过 30 个英文词的句长，不宣称完成句法或理解诊断。短语、熟词僻义和句意仍需结合原文判断。

## 原文、生词与原词书隔离

原文按段显示，可切换提示、调整字号、选择段落；切换段落后保存位置。空行分段，单个换行不强制拆段；标注使用原文偏移，保留标点和内容，不把导入文本渲染成 HTML。阅读资料加载失败时，正文仍保留，可重试或仅阅读原文。

文章库使用独立 IndexedDB `yanxai-articles-v1`、schema 与 revision 检查，不能改写原词书 `AppState`、看词/听音队列、每日目标、错误次数、日历、计划或打卡。多页面写入冲突会报错，不静默覆盖。

文章生词保存来源文章、选定的词典词条、原文段落、出现次数和分析时的 `tokenKey`。复习中的「不认识」增加文章自己的错词次数并重置连续认识；随后显义，继续后稍后重认；连续认识两次后从待完成队列退出。复习结果通过保存的 `tokenKey` 回写本篇标记，避免原形词条与原文变形不同而无法更新阅读报告。这些计数只属于文章，不抵扣词书任务。文章删除时同步删除其生词和阅读记录，需明确确认。

## 容量与备份

| 项目 | 当前限制 |
| --- | --- |
| 材料库 | 最多 50 篇 |
| 单篇正文 | 最多 200,000 字符、20,000 个英文 token |
| TXT 文件 | 最多 2 MiB，必须为 UTF-8 `.txt` |
| 文章生词 | 最多 2,000 条 |
| 文章库及备份 | 20 MiB（20 × 1,024 × 1,024 字节），保存时预留备份 envelope 空间 |

文章数据只保存在当前浏览器，清理站点数据可能清除文章；没有自动云同步。阅读页面右上角的数据操作提供「导出文章备份」「恢复文章备份」「复制备份文本」「粘贴备份恢复」。JSON 格式为 `yanxai-article-library-backup` version 1，包含正文、标题、来源、阅读段落、本篇标记、生词及其复习计数。

**文章备份不包含原词书状态、打卡计划、复述记录、录音、ASR 模型或可重建词典缓存。** 原词书、复述需要使用各自已有的备份流程。恢复先检查 schema、容量、引用、正文 hash 和计数，再预览篇数及生词数；明确确认后替换整个文章库，不合并，也不改词书和复述。错误文件、被修改的正文或并发冲突不会覆盖现有数据。

原生文件下载由浏览器和系统处理，点击按钮只代表请求下载，不能直接宣称已经落盘。如果环境取消 JSON 下载，可以显示并复制完整 JSON 文本，在另一设备通过「粘贴备份恢复」完成同样的严格校验和预览。
