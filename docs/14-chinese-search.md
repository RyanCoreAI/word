# 中文查英文与备份入口

## 查询行为

首页同一个搜索框接收中文或英文。英文保持精确词条优先、其余前缀按字母排序；中文只检索 ECDICT 实际释义，不生成翻译、不猜近义词，也不把短句当成机器翻译。

中文结果按以下顺序比较：完整义项（含“有益／有益的”这种已存在的近似形式）、义项开头、释义内部；同类优先显示靠前的主释义，再按原词频排序。近似形式仅影响已匹配结果的排序，不删除查询中的“的”，不扩大匹配集合。例如“有益”优先 beneficial，“放弃”优先 abandon，“银行”优先 bank；详情保留完整原释义供核对。

输入会做 NFKC、首尾空格及英文大小写规范化，查询内容不作为正则执行。中文输入法组词完成后再查询。保留最多 60 条最佳去重结果；X 清空并回到输入框。

## 本地范围与性能

先显示已加载的 19,106 词学习包。已下载的完整词典随后补充：每批最多读取 1,500 条，采用独立只读事务；更换查询或离开页面会取消旧查询。扫描只保留最佳结果，不把 770,611 个词条一起放入应用内存，也不升级原有学习数据库。

最近 8 次完整中文查询可以复用；缓存键包含词典版本、查询、结果上限和已完成分片的校验收据。同页或其它页继续下载词典后不会复用旧分片集合的结果。当前搜索范围在结果面板显示，部分下载不能冒称查过全部词典。扫描失败保留真实学习包结果并明确提示。

没有下载完整词典时不会为了查词自动下载全部 115 MB；可在设置主动下载／继续下载。查询不发到服务器、不使用付费 AI 或商业翻译接口，不写 AppState、每日量、计划、错误次数或文章数据。

## 备份入口

设置中的“数据与备份”统一包含词书导出／恢复／文本备份，及按需展开的“文章库备份”“复述文字备份”。阅读页不再放数据菜单，复述对照页不再放文字备份按钮。没有定时提醒或通知。

- 词书：沿用完整学习备份，含两种模式、活动记录、计划与打卡；新增巩固排期也必须包含在内。
- 文章库：原有严格 JSON 导出、文件／粘贴恢复和预览确认，含正文、生词、阅读位置；不混入词书或复述。
- 复述文字：导出每篇最近保存的识别文字与时间；不含录音，也不增加未经实现的文字恢复功能。录音仍在原对照页单独下载。

没有改备份文件格式、云同步承诺或原生下载结果的边界。浏览器取消文件下载时，文本导出／复制／粘贴恢复仍是可用路径；不能将自动化代存文件称为系统原生保存成功。

## 采用的标准

批量读取使用 [IndexedDB getAll 的 query/count](https://developer.mozilla.org/en-US/docs/Web/API/IDBObjectStore/getAll) 与 [W3C IndexedDB 事务取消规则](https://www.w3.org/TR/IndexedDB/)，沿用旧浏览器支持较广的两个位置参数，不依赖较新的 options 重载。
