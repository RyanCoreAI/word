# Word · 背单词

Claude 原型风格的免费网页/PWA：看词、听音、本书每日计划与打卡分享、昨日错词复习、经核对的常用搭配、离线语音复述、真实 ECDICT 词库、本机进度及备份恢复。另提供按用户要求制作的安卓 TWA 安装包。当前方案见 [docs/00-web-plan.md](docs/00-web-plan.md)；旧原生方案仅作历史参考。

安卓安装包：[Word 1.0.0 APK](https://word.yanxai.com/downloads/word-android-1.0.0.apk)。需要 Android 7.0+ 与稳定版 Chrome；下载后按系统提示安装，从桌面「背单词」打开。它沿用同一 Chrome 中的本站数据；其它浏览器或设备需先导出备份。不是独立重写的原生学习引擎，首次仍需联网下载词库。源码、构建、签名保留与验收边界见 [android/README.md](android/README.md)。

安全措施、Cloudflare 范围与验证边界见 [安全防护说明](docs/11-security.md)：安全响应头、本站资源策略、严格备份/路径校验及发布目录检查。后台规则的实际启用状态与公网拒绝样例分开记录，不宣称绝对安全。

## 本地运行

需要 Node.js 22.12+（推荐24）、Python 3.12+，无需额外 Python 库。

```sh
npm ci
python tools/pipeline/build.py
python tools/asr/build.py
npm run dev
```

数据管线从固定上游提交下载 CSV、校验 SHA-256、完整导入本地 SQLite，生成学习包与全量静态词库分片。原始数据和生成物不进入 Git。网络首次下载较慢时可重试。

发音只使用浏览器提供的本地英文声音，默认优先本机 Samantha。复述识别独立使用本地 Whisper WASM 包，构建需运行上述 ASR 管线；不生成朗读音频或安装语音服务。安装依赖时可设置 `ONNXRUNTIME_NODE_INSTALL=skip` 跳过不使用的 Node 原生推理后端；CI 已配置。旧 [音频管线](tools/audio/README.md) 保留作历史资料，其生成物不进入当前发布。

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

本机安装 Chrome 后，可运行 `node tools/sw-navigation-smoke.mjs`。它用真实浏览器及 Service Worker 验证静态托管的 HTML 规范地址跳转、旧跳转缓存和离线刷新；无需启动 preview。

preview 启动后，`node tools/experience-smoke.mjs` 检查安卓 Chrome 仿真中的搜索、圆环切换、首见释义、日历与离线恢复；`node tools/audio/browser-smoke.mjs` 检查真实浏览器本机声音及零在线音频请求。仿真不代替手机系统安装、键盘或 Samantha 真机试听。

`node tools/phrases/browser-smoke.mjs` 检查 beneficial / figure 的指定搭配、准确中文、未核对词不显示、手机与桌面搜索清空、键盘焦点、撤下文章朗读及未打开搭配的离线使用。旧 `tools/phrases` 数据生成器和来源快照只作历史资料，不再进入 CI 发布产物。

`node tools/new-learning-smoke.mjs` 检查真实触摸回看、学习页直接显示短语、长单词、快捷设置、昨日错词与安装说明。`node tools/retell-smoke.mjs` 检查完整复述页面、真实录音与转写、本机保存和离线再次识别；需先按 [ASR 验证说明](tools/asr/README.md) 获取公开 JFK 音频作为 Chrome 文件麦克风输入。没有伪造识别或评分结果，文件输入仍不代表安卓真机。

## 数据和发音

- IndexedDB 保存学习快照，逐次写入，失败不会静默推进。多标签页通过 revision 防止旧记录覆盖。
- 全量词库分片校验后入库，已完成分片可复用。学习包和全量词库独立。
- 备份是完整 JSON，可导入同词库版本。换设备需要手动恢复；没有云端账号或同步。
- 默认优先本机 Samantha，其次同口音本地英文声音；不使用远程声音或本站 Piper。安卓需在系统中安装英文语音数据，浏览器没有暴露可用本地声音时会提示不可用。切词取消旧声音，只有真实 `onstart` 才允许听音作答。
- 首次出现的词点认识，保存后显示词义约 1.1 秒再自动继续；两模式中已经答过的词再次认识时立即继续。
- 右滑回看已作答的词，左滑往后到当前待学词停止；回看不撤销、不再次作答、不改计数。保留最近 1,000 次两模式学习轨迹，旧进度兼容，不补造旧轨迹。桌面和无手势环境提供回看按钮。
- 前一天各模式点过不认识且未斩的词，今天在下一新组优先再检验一轮，包含昨天后来已掌握的词；跨午夜保持当前组，不插队或重复发放。答错继续原有两次认识规则，撤销与备份包含每日检验标记。
- 认识按钮右侧的「斩」长期跳过当前词，首次解释含义并支持立即撤销；跳过不计入错误或当天背词数，也可在生词本恢复。
- 开始学习请求 12ms 轻震，斩词保存成功后播放本机生成的 160ms 刀切音效；设置里可分别关闭。不支持触感或音频时不影响学习，按钮提供立体阴影和按下反馈。
- 首页可切换看词/听音进度，圆环首次打开旋转一次；日历按本机日期记录当天去重词数、词义和错误次数，撤销同步回退。旧备份兼容，无法恢复的旧日期不补造。
- 安卓可从安装入口或 Chrome 菜单安装为 PWA，独立窗口、主屏图标和离线学习，无需商店开发者账号。双击不缩放，保留双指缩放。
- 词典音标保留来源原文，不宣称已按英美或所有词性校准。
- 当前 33 个词条、39 条搭配。看词和听音揭晓、回看显示经核对的常用搭配及中文，详情可展开来源；如 `beneficial → be beneficial for / to`、`figure → figure out`。按词条精确关联，不再显示旧词组和 WordNet 近义块，未核对词不显示补充区域。中文为编辑释义，附直接支持搭配的权威用法链接，不复制词典整段释义或例句；随应用外壳离线可用，不宣称全词覆盖或官方词频排名。
- 首页和生词本搜索均有 × 清空按钮，清空立即收起旧结果并保留输入焦点。
- 长单词按实际字体宽度缩小，优先单行；极长词不缩成不可读的小字。

## 本书计划与打卡分享

首页圆环卡在上，今日计划卡在下。计划按词书与看词/听音独立保存，显示本书今日还需新学/复习的数量及剩余/总天数。开始日和截止日按设备当地日期计算，包含今天；每日新词目标由未接触余额和剩余天数向上取整，当天固定。修改截止日期时重新计算当前日目标，保留已有计数、原开始日与过去记录；“重置”只调整编辑中的截止日期，不清学习进度。到期仍可继续学习。

首次在当前模式作答计一个新词，重复遇见不重复计数；不认识也算已经接触过，仍按原规则巩固。昨日在本书答错的词单独复习一轮，不抵扣新词目标。已有旧进度会扣除未学余额，不补造首次学习日期或旧打卡。保存时固定基础词过滤范围，后续改全局过滤会提示重新保存计划；已斩词排除，旧队列中其它词书的复习不计本书任务。两项达标后可打卡，继续学习入口一直保留。

真实活动达标后先保存一次礼炮凭据，再播放短暂动画；尊重减少动画设置，零任务日不伪造礼炮成就。撤销回退当日计数及打卡状态，但已领取过的礼炮不重复。完整单词 JSON 备份包含计划、每日新学/复习记录、打卡与礼炮凭据；不包含复述录音。

打卡图使用已保存的真实词数，在本机生成 1080×1584 PNG；20 张同源风景可切换，二维码固定为 [Word 官网](https://word.yanxai.com/)，不含个人进度链接。风景按选择请求并缓存，不会在安装时一次下载全部图片。已缓存的图片可离线再用，未缓存的风景需联网，失败可重试。

“分享图片”调用手机系统分享面板，具体目标取决于浏览器和已安装应用；不能保证直接选择某个微信/QQ会话或证明发送成功。系统不支持时可保存图片、复制官网链接后手动发送。安卓用 Chrome 打开官网，通过安装入口或浏览器菜单“安装应用/添加到主屏幕”作为 PWA 使用，无需商店开发者账号。桌面和手机尺寸仿真不等于真实安卓的安装、分享、下载或动画性能验收。

`node tools/study-plan-smoke.mjs` 检查浏览器中的计划编辑、真实作答达标、打卡后继续、撤销、词书/模式切换与备份等流程；`node tools/check-in-share-smoke.mjs` 检查分享图导出、二维码解码、20 图切换及缓存/失败处理。两个脚本的实际运行结果与真机边界应在交付时单独报告。

## 语音复述

新增「复述」导航：阅读短文 → 隐藏原文 → 只用麦克风复述 → 对照两份编辑参考、三个中文要点和易错提示 → 回听后再说。首批四篇为附研究/官方来源的原创教学改写，不是官方雅思材料或官方分级；不提供假的语义、语法、发音或雅思自动分数。

按用户要求，文章合成朗读达不到自然语气标准，已撤下文章听音入口；保留单词本机发音与自己录音的回听。不把调语速、固定停顿或声音事件测试声称为真人听感。

识别使用本机 Whisper tiny.en q8，通过独立 Worker 与 WASM 运行。用户点击后首次从本站下载约 73 MB，分片/组装均校验，缓存约需 146 MB；应用外壳不会自动下载模型。不用收费账号、外部 API 或语音识别服务器，不上传录音。真实识别有误差，低端手机速度取决于设备；可以取消、回听和重试。

每篇只在独立 IndexedDB 保存最近一次完成的实际识别文字与录音。单词「完整备份」涵盖学习进度，不包含复述录音；复述页另有只读文字导出/复制及录音下载。清除网站数据前须分别保存，当前没有跨设备语音记录恢复/合并。

## 发布

`dist/` 是完整静态产物。GitHub Actions 在当前仓库分支运行检查、真实数据管线和构建并保存产物；线上发布使用 Cloudflare Workers 的纯静态资源托管，无 Worker 业务函数、云数据库、邮件或付费套餐。静态资源请求免费，见 [官方说明](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)。

`wrangler.jsonc` 仅配置独立项目 `yanxai-word` 与子域 `word.yanxai.com`。使用现有 Wrangler OAuth 登录运行 `npm run deploy`；Cloudflare Custom Domain 自动管理本子域的 DNS 和证书，不更改根站及其它项目。CLI 版本固定为 4.151.3，不将授权令牌提交到 Git。

本项目 `_headers` 只为应用文档添加 `Cache-Control: no-transform`，按 [Cloudflare 官方说明](https://developers.cloudflare.com/web-analytics/faq/) 阻止代理自动插入统计脚本；不修改全域或其它站点的设置。`node tools/hosting-privacy-smoke.mjs` 用实际浏览器导航验证响应头、HTML 字节和零第三方/统计请求，避免仅用非浏览器 GET 漏掉条件注入。

构建检查风景目录恰好为 `01.png`–`20.png`、PNG 完整性、至少1080×800及20个不同 SHA-256；可先运行只读的 `node tools/build-offline.mjs --check-scenes-only`，不改现有构建。发布后运行 `node tools/verify-release.mjs`，比较全部本地 JS/MJS/CSS 分块、20 张图片、许可及原有词库/ASR 文件的线上字节，含 canvas-confetti ISC 与 qrcode MIT 许可。分享图需要的风景按需缓存，不纳入应用安装预缓存。

用户进度及备份不要提交到仓库。清除网站数据会删除本机进度，请定期导出备份。
